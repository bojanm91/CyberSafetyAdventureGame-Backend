# CyberSafetyAdventureGame-Backend

NestJS backend za početnu verziju Cyber Safety Adventure aplikacije.

## Start

```bash
npm install
npm run start:dev
```

## API

- `GET /api/health`
- `GET /api/content/landing`
- `GET /api/content/missions`
- `GET /api/content/dashboard`
- `POST /api/auth/login`
- `POST /api/auth/register`
- `GET /api/progress/me`
